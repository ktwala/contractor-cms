## South Africa (ZA)

### Governing Legislation
- **Basic Conditions of Employment Act (BCEA)** - Act 75 of 1997
- **Labour Relations Act** - Act 66 of 1995
- **Unemployment Insurance Act** - Act 63 of 2001

### Annual Leave

| Attribute | Value |
|-----------|-------|
| Entitlement | 21 consecutive days OR 15 working days per year |
| Accrual Rate | 1.25 working days per month |
| Accrual Start | From first day of employment |
| Carry Over | Must be taken within 6 months of end of leave cycle |
| Payment in Lieu | Only permitted on termination of employment |
| Pro-rata on Termination | Yes - paid out based on accrued balance |
| Minimum Service | None - accrues immediately |

### Sick Leave

| Attribute | Value |
|-----------|-------|
| Entitlement | 30 working days per 3-year cycle |
| Cycle Calculation | Equivalent to number of days employee would work in 6 weeks |
| First 6 Months | 1 day for every 26 days worked |
| Medical Certificate | Required for absences > 2 consecutive days |
| Medical Certificate | Required if absent > 2 occasions in 8 weeks |
| Payment | Full pay |
| Accumulation | Does NOT accumulate beyond the cycle |
| Unused Balance | Forfeited at end of 3-year cycle |

### Maternity Leave

| Attribute | Value |
|-----------|-------|
| Entitlement | 4 consecutive months (17.32 weeks) |
| Earliest Start | 4 weeks before expected date of birth |
| Latest Start | Date of birth |
| Return Restriction | Cannot work for 6 weeks after birth (unless medical clearance) |
| Payment by Employer | **Unpaid** (unless company policy provides otherwise) |
| UIF Claim | Yes - up to 66% of earnings (capped) |
| UIF Maximum | Based on earnings threshold (updated annually) |
| Job Protection | Yes - cannot be dismissed for pregnancy |
| Notice Required | 4 weeks written notice |

### Paternity Leave (Parental Leave)

| Attribute | Value |
|-----------|-------|
| Entitlement | 10 consecutive days |
| Effective Date | January 2020 (Labour Laws Amendment Act) |
| Eligibility | Father of child OR life partner of mother |
| Timing | Must commence from date of birth |
| Payment by Employer | **Unpaid** |
| UIF Claim | Yes - can claim from UIF |
| Adoption | Also applies to adoptive parents |
| Commissioning Parents | Also applies (surrogacy arrangements) |

### Family Responsibility Leave

| Attribute | Value |
|-----------|-------|
| Entitlement | 3 days per annual leave cycle |
| Qualifying Service | 4+ months of employment |
| Valid Reasons | Birth of employee's child |
| | Illness of employee's child |
| | Death of spouse/life partner, parent, adoptive parent, grandparent, child, adopted child, grandchild, sibling |
| Payment | Full pay |
| Documentation | Employer may require reasonable proof |
| Accumulation | Does NOT accumulate - forfeited if unused |

### Study Leave

| Attribute | Value |
|-----------|-------|
| Statutory Entitlement | **None** - contractual only |
| Common Practice | Varies by employer policy |

### Public Holidays (12 days)

| Date | Holiday |
|------|---------|
| 1 January | New Year's Day |
| 21 March | Human Rights Day |
| Varies | Good Friday |
| Varies | Family Day (Easter Monday) |
| 27 April | Freedom Day |
| 1 May | Workers' Day |
| 16 June | Youth Day |
| 9 August | National Women's Day |
| 24 September | Heritage Day |
| 16 December | Day of Reconciliation |
| 25 December | Christmas Day |
| 26 December | Day of Goodwill |

**Note:** When a public holiday falls on a Sunday, the following Monday is observed.

## Lesotho (LS)

### Governing Legislation
- **Labour Code Order 1992**
- **Labour Code (Amendment) Act 2000**

### Annual Leave

| Attribute | Value |
|-----------|-------|
| Entitlement | 12 working days per year |
| Accrual Rate | 1 working day per month |
| Qualifying Period | **12 months continuous service required** |
| First Year | No statutory annual leave entitlement |
| Carry Over | As per employment contract (no statutory requirement) |
| Payment in Lieu | Only permitted on termination |
| Pro-rata on Termination | Yes - for completed months after first year |

### Sick Leave

| Attribute | Value |
|-----------|-------|
| Entitlement | 14 working days per year |
| Medical Certificate | Required for absences > 3 consecutive days |
| Payment | Full pay |
| Accumulation | **Does NOT accumulate** - resets annually |
| Unused Balance | Forfeited at end of year |
| Extended Illness | Employer may grant unpaid leave |

### Maternity Leave

| Attribute | Value |
|-----------|-------|
| Entitlement | 12 weeks (84 calendar days) |
| Timing | 6 weeks before expected birth, 6 weeks after |
| Flexibility | Can adjust timing with medical approval |
| Payment by Employer | **Yes - 2/3 (66.67%) of normal wages** |
| UIF Equivalent | **Not available** (no UIF in Lesotho) |
| Job Protection | Yes - cannot be dismissed for pregnancy |
| Notice Required | Reasonable notice with medical certificate |
| Qualifying Period | None specified |

### Paternity Leave

| Attribute | Value |
|-----------|-------|
| Statutory Entitlement | **None** |
| Common Practice | Some employers provide 2-5 days as company policy |
| Payment | If provided, typically full pay |

### Family Responsibility Leave

| Attribute | Value |
|-----------|-------|
| Statutory Entitlement | **None** |
| Common Practice | Compassionate leave may be provided by employer |
| Bereavement | Often 3-5 days by company policy |

### Study Leave

| Attribute | Value |
|-----------|-------|
| Statutory Entitlement | **None** |
| Common Practice | Varies by employer |

### Public Holidays (10 days)

| Date | Holiday |
|------|---------|
| 1 January | New Year's Day |
| 11 March | Moshoeshoe's Day |
| Varies | Good Friday |
| Varies | Easter Monday |
| 4 April | Heroes' Day |
| 1 May | Workers' Day |
| Varies | Ascension Day |
| 17 July | King's Birthday |
| 4 October | Independence Day |
| 25 December | Christmas Day |
| 26 December | Boxing Day |

## Payroll Integration Impact

### Leave Affecting Pay Calculation

| Scenario | South Africa | Lesotho |
|----------|--------------|---------|
| **Unpaid Leave** | Deduct: (Monthly Salary / 21.67) × days | Deduct: (Monthly Salary / 22) × days |
| **Maternity Leave** | No deduction (unpaid, UIF claim) | Pay 66.67% of normal salary |
| **Sick Leave (within entitlement)** | Full pay | Full pay |
| **Sick Leave (exceeded)** | Unpaid or company policy | Unpaid |
| **Annual Leave** | Full pay | Full pay |
| **Public Holiday Worked** | Double pay or day in lieu | 1.5x pay or day in lieu |

### Daily Rate Calculations

```
South Africa:
  Daily Rate = Monthly Salary ÷ 21.67 (average working days)
  Hourly Rate = Daily Rate ÷ 8 (or contracted hours)

Lesotho:
  Daily Rate = Monthly Salary ÷ 22 (average working days)
  Hourly Rate = Daily Rate ÷ 8 (or contracted hours)
```

### Leave Provision (Financial Liability)

Leave balances represent a financial liability that should be:
1. Calculated monthly for accrued but untaken leave
2. Reported in financial statements
3. Journaled to appropriate GL accounts

```
Leave Liability = Σ (Employee Leave Balance × Employee Daily Rate)
```

## Adding New Countries

When adding a new country to the platform, document the following:

### Required Information Checklist

```
□ Governing legislation name and reference
□ Annual leave entitlement and accrual rules
□ Sick leave entitlement and cycle
□ Maternity leave duration and payment rules
□ Paternity leave (if applicable)
□ Family responsibility leave (if applicable)
□ Public holidays with dates
□ Working days per month calculation
□ Social security/insurance schemes affecting leave
□ Medical certificate requirements
□ Notice periods for leave requests
□ Carry-over and forfeiture rules
□ Termination payout requirements
```

### Country Configuration Template

```typescript
interface CountryLeaveConfig {
  countryCode: string;
  workingDaysPerMonth: number;
  workingHoursPerDay: number;

  annualLeave: {
    entitlementDays: number;
    accrualRatePerMonth: number;
    qualifyingMonths: number;
    maxCarryOverDays: number;
    carryOverExpiryMonths: number;
    payoutOnTermination: boolean;
  };

  sickLeave: {
    entitlementDays: number;
    cyclePeriodYears: number;
    certificateRequiredAfterDays: number;
    accumulatesAcrossCycles: boolean;
  };

  maternityLeave: {
    entitlementWeeks: number;
    employerPaidPercentage: number;
    socialInsuranceClaim: boolean;
    socialInsurancePercentage: number;
  };

  paternityLeave: {
    entitlementDays: number;
    employerPaidPercentage: number;
    socialInsuranceClaim: boolean;
  };

  familyResponsibilityLeave: {
    entitlementDays: number;
    validReasons: string[];
  };

  publicHolidays: Array<{
    name: string;
    month: number;
    day: number | 'easter_friday' | 'easter_monday' | 'ascension';
    observeNextMonday: boolean;
  }>;
}
```
